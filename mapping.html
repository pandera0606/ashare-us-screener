板块按 GICS 一级行业，另可增补非 GICS 板块（如加密货币）。原来的主题维度改成概念标签，一只美股可挂多个概念。 可增删板块 / 概念、对应 A 股、美股及其 A 股映射（对标 / 供应链 / 同概念 / ADR）。 「保存到本机」写入这个浏览器；用 GitHub Pages 或 python tools/serve.py 打开时，刷新研究台即可生效。 双击本地 HTML 打开时两个页面存储不互通，请再「下载种子文件」覆盖 js/data/mapping-seed.js。 日榜脚本读的是种子文件，改完后需重跑 fetch_board.py 才会进入日榜池。
